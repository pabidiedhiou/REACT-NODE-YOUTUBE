# React and Node starter

An early React and Node learning scaffold. The `client/` directory contains a Create React App project with its default welcome screen. The root `package.json` lists Express and dotenv, but this repository does not include an implemented server entry point or API routes.

## View the client

```bash
cd client
npm install
npm start
```

Open http://localhost:3000 to see the starter screen. Run `npm run build` from `client/` to build it.

## Status

This repository records a starting point for a React and Node exercise. It does not yet implement the application suggested by its name.
